# Next.js Learning Log

A personal learning journal for Next.js 16 (App Router). This project documents the entire journey of studying Next.js from fundamentals to production-ready apps — sessions, notes, examples, mistakes, and useful references.

**Language:** English (Ukrainian for complex explanations)
**Environment:** Node.js + Next.js 16, React 19

## Project Structure

```
├── sessions/        # Dated learning session diary (Pomodoro log)
├── notes/           # Concept summaries, tips, and references
├── examples/        # Practical examples and mini-projects
├── mistakes/        # Documented mistakes and lessons learned
├── cheatsheets/     # Quick reference sheets (CLI, hooks, APIs)
├── exercises/       # Practice tasks with solutions
├── components/      # Reusable React/Next.js component examples
├── templates/       # Templates for consistent documentation
├── youtube/         # Thumbnails, controls, todo for streams
├── glossary.md      # Next.js & React terminology dictionary
├── ROADMAP.md       # Learning plan and goals
├── PROGRESS.md      # Tracking what has been accomplished
├── RESOURCES.md     # Curated learning resources
```

## Quick Start

```bash
npx create-next-app@latest my-app --typescript --tailwind --app
cd my-app
npm run dev
```

## How to Use

1. Follow the [ROADMAP](ROADMAP.md) for the learning path
